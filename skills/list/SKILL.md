# 実行手順（毎回必ずこの順で実施）

## ステップ1: 最新コマンド一覧を公式から取得

WebFetch ツールで以下URLから最新の全コマンド・引数・説明を取得:

```
https://code.claude.com/docs/en/commands.md
```

WebFetch のプロンプト:

> Claude Code（CLI）の全スラッシュコマンドを、コマンド名・引数・説明・エイリアスをそのまま列挙してください。カテゴリ分けがあれば保持。新規追加・廃止コマンドも明示してください。省略せず全コマンドを網羅。

## ステップ2: カテゴリ別整理 + 実用例追加

取得したコマンドを以下のカテゴリで整理し、**各コマンドに業務シーンに即した具体例**を必ず1行つける:

1. **ワークフロー別ショートガイド**（プロジェクト初期化 / 作業中 / 仕上げ前 / セッション間 / トラブル時）
2. **セッション管理**
3. **コンテキスト・メモリ**
4. **モデル・実行制御**
5. **計画・レビュー**
6. **自動化・並列実行**
7. **診断・トラブル**
8. **設定・UI**
9. **連携・拡張**
10. **情報・分析**
11. **ファイル・出力**
12. **モバイル・デスクトップ**
13. **クラウド・リモート環境**
14. **その他・特殊**
15. **廃止済み**（あれば）

## ステップ3: フォーマット

各コマンドは以下の形式で出力:

```
**`/コマンド名 [引数]`** - 簡潔な用途（alias があれば併記）
> 例: 業務シーンに即した具体的なシチュエーション
```

実用例の参考シーン（汎用的な業務例を使う）:

- Web アプリ開発（フロントエンド/バックエンド、Vercel/Cloud Run デプロイ）
- 業務自動化ツール（経費精算/勤怠管理/月次レポート/データバックアップ）
- API 連携（LINE Bot/Slack Bot/Gmail/Calendar/Drive）
- データ処理（CSV/PDF/Excel の自動加工）
- 顧客対応（問い合わせ管理/サポート Bot）
- マーケティング（SNS 分析/コンテンツ生成/SEO 改善）
- 営業（提案資料作成/日報自動化/CRM 連携）
- インフラ運用（監視/アラート/障害対応）
- セキュリティ（コードレビュー/脆弱性検出/シークレット管理）
- AI/ML（モデル学習/推論/プロンプト最適化）

## ステップ4: 注意点を末尾に明記

- 全コマンドが全員に表示されるわけではない（プラットフォーム/プラン/環境依存）
- MCP プロンプトは `/mcp__<server>__<prompt>` 形式で接続済みサーバーから動的追加
- 公式ドキュメント: https://code.claude.com/docs/en/commands.md
- 取得日時: 実行時刻を表示

## ステップ5: 出力ルール

- カテゴリ別に `## 見出し` で分類
- テーブル不要、見やすい箇条書きで
- 抽象的説明は避け、必ず実シーンを書く
- 前置き不要、即本題
- 全コマンド網羅（省略禁止）
- 廃止コマンドは末尾に専用セクションで掲載

## 出力例（フォーマット参考）
